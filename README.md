## 📌 About

**Sigma Prime Course** is a complete Full-Stack Development learning repository inspired by Apna College.  
This repository contains structured code and practice modules covering frontend, backend, and databases.

---

## 🛠 Tech Stack Covered

- 🌐 HTML5, CSS3
- 🎨 Bootstrap 5, Tailwind CSS
- ⚙ Node.js
- 🚀 Express.js
- 🛢 MongoDB
- 🗄 SQL / MySQL
- 📦 EJS Templates
- 🔗 REST APIs

## 🔧 Setup & Run

```bash
# Clone Repository
git clone https://github.com/yourusername/SIGMA-PRIME-COURSE.git

# Enter Folder
cd SIGMA-PRIME-COURSE

PORT=3000
MONGO_URI=your_mongodb_connection
SQL_HOST=localhost
DEBUG=true

# Install Dependencies (if backend used)
npm install

# Start Server
npm run dev
